# README.md — Система бронювання коворкінгу

## Опис домену

**Система бронювання коворкінгу** — це платформа для керування простором спільної роботи (coworking space), де:

- **Користувачі** реєструються як члени коворкінгу
- **Простори** (офісні кімнати, конференц-зали, робочі місця) доступні для бронювання
- **Бронювання** — це резервування простору на конкретний день/час
- **Пакети членства** визначають права доступу та кількість днів/годин на місяць
- **Платежі** відстежують оплату членства та додаткових послуг
- **Оцінки та коментарі** дозволяють користувачам залишати відгуки про простори

## Мета

Розробити нормалізовану ER-модель, яка:
- Описує всі сутності та їх зв'язки
- Забезпечує коректні кардинальності
- Підтримує бізнес-логіку коворкінгу

## Структура проекту

- `spec.md` — специфікація сутностей, атрибутів, зв'язків
- `ermodel.md` — ER-діаграма в синтаксисі Mermaid
- `DEFENSE.md` — обґрунтування моделі та результати аудиту
- `design-decisions.md` — архітектурні рішення
- `audit.md` — аудит синхронізації моделі

## Домен обраний: **Система управління простором коворкінгу**

Цей домен:
✅ Має достатню складність для нормалізації  
✅ Містить декілька зв'язків 1:M та асоціативну сутність для моделювання Member-Membership  
✅ Близький до реальних бізнес-систем  
✅ Дозволяє продемонструвати уміння моделювання даних
